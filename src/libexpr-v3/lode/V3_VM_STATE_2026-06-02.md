## 1. What it is (one paragraph)

v3 is an **STG-inspired, V8-influenced bytecode VM for Nix**. As of the parser landing (2026-06-01) it is **fully native end-to-end**: `.nix` text → v3 AST → v3 IR → bytecode → VM dispatch, with **no `nix::Expr` anywhere in the path**. The tree-walker (cppnix) is now used only as a set of **libraries linked at FFI leaves** (store, fetchers, flake-lock, realise) — not as an evaluator v3 trades value-graphs with. The end-state is **V3-NATIVE**: v3 owns evaluation; TW permitted ONLY at FFI leaves; no `nix::Expr` (done), no `nix::Value` marshalling (in progress), one `ffi.h`, mechanically enforced by a CI lint. Targets are both wall-parity (≤1.3-1.5× TW; honest ceiling ~1.5-2× native given the interpreter+PIC bound) and — increasingly the primary lever — peak RSS (M5 cardano-node under a 4 GB watchdog).

## 4. Value & memory model

- **`Value` = 16 bytes** (`static_assert`, `value.hh:230`): low byte is the `Tag`, rest an 8-byte payload union. 18 tags: scalars (Int/Float/Bool/Null), text (String/Path = `const char*` into arena), heap (Attrs→Bindings, List→ListVec, Closure, Thunk, App/App3/PrimOpApp→ValuePair, Slot→Value*), PrimOp (static), Blackhole, External (opaque TW handle), Uninitialized. `tagIsPointer()` is the single GC-tracing source of truth, fenced by static_asserts.
- **`ValuePair` = 64 B** (`left/right/evaluated/third`; `App3`=Tag 17 uses `third`, keeps `evaluated` as App's memo sink).
- **`Closure`** {desc, cu, capturedWiths, nUpvalues, upvalues[FAM]}; **`Thunk`** {state(Suspended/Blackhole/Evaluated/Native/Bridge), cell, cellContainer, shapeCell, union, tail[FAM]}; **`LambdaDescriptor`** = shared blueprint (codeOffset, arity, formals, Intrinsic, cachedSingletonClosure).
- **Default allocator: Boehm conservative GC** (inherited from cppnix), v3 arena registered via `GC_add_roots`. The Cheney **nursery** (Phase A/C/E) and the **Immix major GC** (`mark_sweep.cc`) are both **gated, default-OFF**. **Phase D write barriers default-ON** (`NIX_V3_NO_PHASE_D` opts out).
- **`alloc.hh` has NO `madvise`/`munmap`** — append-only arena. This is THE architectural pin behind 11 memory falsifications (§5).
- **Schema version 16** (`serialize.hh:171`); disk-cache rows keyed `(key, schema)`.

### 5.8 Explicitly killed / falsified — *abandoned, not gaps*
